منصة تعليم — النسخة الدافئة التجريبية
======================================

الملفات الموجودة في الحزمة:
- index.html : صفحة تشغيل الموقع.
- config.js  : اسم المنصة وإعدادات المواد والهدف اليومي.
- style.css  : التصميم المتجاوب والوضع الداكن.
- app.js     : الحسابات التجريبية والصفحات والاختبارات والتقدم والإنجازات والرسائل المحلية.

طريقة التشغيل:
1) فك ضغط ZIP.
2) ارفع الملفات الأربعة كما هي إلى جذر استضافة الموقع، أو افتح index.html للتجربة.
3) أنشئ حسابًا تجريبيًا من داخل الصفحة.
4) استخدم GitHub Pages أو استضافة static عند الحاجة للنشر. بعض المتصفحات قد تقيّد التخزين المحلي عند فتح الملف مباشرة؛ الاستضافة عبر HTTPS أفضل.

مهم قبل النشر الحقيقي:
- هذه النسخة تحفظ الحسابات والأسئلة المُجاب عنها والرسائل في localStorage على الجهاز الحالي.
- حسابات الطلاب ولوحة المتصدرين والمحادثات ليست مشتركة عبر الإنترنت.
- كلمة مرور النسخة التجريبية ليست نظام مصادقة آمنًا؛ لا تستخدم بيانات حقيقية أو حساسة.
- حقولا Supabase في config.js لا يعنيان أن Supabase متصل بالفعل. لتشغيل منصة عامة نحتاج إعداد Supabase Auth وقاعدة بيانات وسياسات RLS، ثم ربط app.js بها.
- بنك الأسئلة الموجود في app.js هو بنك مبدئي مضمّن في هذه الحزمة، ويمكن توسيعه وإضافة بقية أسئلتك إليه.

ملاحظات:
- الملفات مباشرة في جذر ZIP وليست داخل مجلد إضافي.
- لا توجد مكتبات بناء أو تثبيت مطلوبة، والخط العربي يُحمّل من Google Fonts عند توفر الإنترنت.
