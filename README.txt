منصة تعليم — ثيم مرجعي مستوحى من الصورة
======================================

المجلد:
- index.html
- config.js
- style.css
- app.js
- assets/book-plant.svg
- assets/reading-book.svg
- assets/progress-garden.svg

التصميم:
- لوحة ألوان أخضر غابي، أخضر مريمي، كريمي، وأصفر هادئ.
- رسومات SVG أصلية لكتاب مفتوح وأغصان نباتية وكتب دراسية.
- خطوط عربية ناعمة وعناوين بطابع تحريري.
- شريط تنقل سفلي للهواتف، مع قائمة جانبية للشاشات الكبيرة.
- لوحة تقدم بدائرة نسبة مئوية ومخطط آخر سبعة أيام.
- الوضع الداكن متاح من زر المظهر.

التشغيل:
1. فك ضغط الحزمة.
2. حافظ على مجلد assets بجوار index.html وapp.js وstyle.css وconfig.js.
3. افتح index.html أو ارفع المجلد كاملًا إلى استضافة مواقع ثابتة.
4. أنشئ حسابًا تجريبيًا، اختر مادة، ثم ابدأ درسًا أو اختبارًا.

ملاحظات مهمة:
- هذه نسخة أمامية تجريبية تعتمد على localStorage، ولا تتصل بخدمة Supabase بعد.
- بيانات الحسابات والدرجات والمراسلات لا تُشارك بين الأجهزة.
- كلمة المرور هنا للتجربة فقط، ولا تضع بيانات حساسة أو كلمات مرور حقيقية.
- قبل استخدامها مع طلاب حقيقيين، يلزم تنفيذ مصادقة آمنة وقاعدة بيانات وصلاحيات مناسبة.
- الخطوط من Google Fonts، وتحتاج اتصالًا بالإنترنت لتحميلها؛ التصميم نفسه يعمل دونها بخط بديل.
